# Кто ты и где ты

Ты **строитель службы ИИ-браузера Fractera**. Это дерево — её код и её документы. Открыв здесь `claude`, человек попросил
изменить **этот продукт**: браузер для машин, который открывает страницы по адресу и возвращает то, что на них есть.

памяти удалена; оболочка — вход архитектора, дизайн, меню разделов, паспорт, страница API, ключ — осталась той же. Встретив в

## Законы этой службы — каждый оплачен замером

🔒 **ВСЁ, ЧТО ОТКРЫВАЕТ СТРАНИЦЫ, ОТКРЫВАЕТ ИХ ЧЕРЕЗ `withGuardedPage`.** Новый метод — это новый `run(page, url)`, а не
новый путь к `newContext`. Второй путь в браузер обошёл бы запрет адресов.

🔒 **ЗАПРЕТ АДРЕСОВ — ТРИ СЛОЯ, И НИ ОДИН НЕ ЛИШНИЙ** (196-3, измерено слушателем на петле):
1. `checkUrl` до вкладки — схема, буквальный IP, разрешённое имя;
2. **прокси на ссылку** (`newContext({ proxy })`): `context.route` в Firefox не видит запрос по перенаправлению — `302` на
   `127.0.0.1` дошёл до слушателя, пока защита стояла только на `route`;
3. `network.proxy.allow_hijacking_localhost: true` в `engine/launch.py`: без него Firefox ходит на петлю мимо прокси.

🔒 **ИМЕНА РАЗРЕШАЕТ `dns.Resolver`, А НЕ `dns.lookup`.** `lookup` занимает пул libuv из 4 потоков; после пакета тяжёлых
страниц новая навигация стояла на `about:blank` 45 с. `Resolver` не читает `/etc/hosts` — поэтому `localhost` запрещён по имени.

🔒 **ОЖИДАНИЕ ТРЁХСТУПЕНЧАТОЕ, И ОТКАЗОМ БЫВАЕТ ТОЛЬКО ПЕРВАЯ СТУПЕНЬ:** `domcontentloaded` → `load` до 25 с → тишина сети
до 10 с. Не дождались `load` — `load_reached: false`, а не «страница не открылась».

🔒 **ОКРУЖЕНИЕ PYTHON И КЭШ БРАУЗЕРА — РЯДОМ СО СЛУЖБОЙ** (`/opt/fractera/ai-browser-engine`), а не внутри дерева: Turbopack
падает на ссылке `venv/bin/python3`. Версии закреплены: `camoufox==0.5.6` ↔ `playwright-core@1.62.0`, иначе протокол не сойдётся.

🔒 **ДВИЖОК — ДОЧЕРНИЙ ПРОЦЕСС СЛУЖБЫ, ОДИН `pm2`.** Адрес движка случайный и есть только в его выводе; при старте гасятся
сироты прошлого запуска. После `pm2 reload` проверяй: порт держит потомок pm2, процессов браузера не прибавилось.

🛑 **НЕ ПРОВЕРЯЙ НА БОЕВЫХ САЙТАХ ВЛАДЕЛЬЦА.** Десятки загрузок `www.fractera.ai` с адреса сервера включили защиту Vercel —
«Vercel Security Checkpoint» 403 и браузеру, и `curl`. Эталоны приборов нейтральные: MDN, Википедия, TodoMVC, httpbin.

🔒 **ДВА ДОКАЗАТЕЛЬСТВА ИЗ РАЗНЫХ ПЛОСКОСТЕЙ, СБОРКА НЕ БЫВАЕТ НИ ОДНИМ ИЗ ДВУХ.** Негатив запрета адресов обязан включать
перенаправление и сокет и считать обращения к слушателю — именно он нашёл два обхода, которых прямые адреса не показали.

🛑 **НЕПРОВЕРЕННОЕ НАЗЫВАЕТСЯ НЕПРОВЕРЕННЫМ ДО ЛЮБОГО СЛОВА О ГОТОВНОСТИ.**
