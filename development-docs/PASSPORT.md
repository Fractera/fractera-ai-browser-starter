# Паспорт службы ИИ-браузера Fractera

## 1. Что это
Настоящий браузер для машин. На каждом сервере Fractera работает браузер Camoufox (форк Firefox, созданный для автоматизации)
за маленьким HTTP-договором. Память — первой, — другие службы и агенты открывают страницу или веб-приложение по адресу и
получают итоговый HTML после работы скриптов и весь видимый текст.

## 2. Где живёт
Папка `/opt/fractera/ai-browser`, порт `3800` на петле, процесс pm2 `fractera-ai-browser`, субдомен `ai-browser.<домен>`.
Ставится на каждый сервер всегда, без выбора — закон платформы о микрослужбах.

## 3. Как устроена
- Движок — `xvfb-run -a python -m camoufox server`: у команды нет параметров, и браузер запускается с окном, поэтому нужен
  виртуальный дисплей. Служба сама запускает движок дочерним процессом: адрес подключения случайный при каждом запуске и есть
  только в выводе движка.
- Служба подключается к движку через `playwright-core` той же версии, что Python-`playwright` у `camoufox` (1.62.0).
- Остановка службы гасит всю группу процессов движка: браузер занимает около 650 МБ памяти.
- Кэш браузера — около 1,5 ГБ в `engine/cache`.
- Страница службы — копия страницы службы памяти (слово владельца).

## 4. Договор сегодня
| Адрес | Что делает | Замок |
|---|---|---|
| `GET /v1/health` | жива ли служба и поднят ли движок | открыт |
| `GET /v1/contract` | договор машинно | ключ или секрет машины |
| `POST /v1/read` | одна страница: итоговый адрес, код, заголовок, итоговый HTML, текст | ключ или секрет машины |
